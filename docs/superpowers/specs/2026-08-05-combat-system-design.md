# 픽셀 월드 전투 시스템 설계

## 목표

현재 이동과 온라인 위치 동기화 중심인 픽셀 월드에 짧지만 완결된 전투 루프를 추가한다. 플레이어는 방향키로 이동하고, Ctrl 기본 공격과 Q 강한 공격으로 중앙 초원의 슬라임 3마리를 처치할 수 있다. 피격, 밀쳐내기, 사망 소멸, 플레이어 부활까지 한 사이클로 완성한다.

## 확정 조작법

- 방향키 위·아래·왼쪽·오른쪽: 이동
- Ctrl 왼쪽 또는 오른쪽: 기본 검 공격
- Q: 강한 공격
- Esc: 게임 나가기
- 기존 WASD 이동과 빈 슬롯 알림 동작은 제거한다.
- 브라우저 기본 동작이 게임 입력을 방해하지 않도록 게임 실행 중 관련 키 입력을 처리한다.

## 충돌

- 월드 경계, 사막 도시, 태고의 나무, 빙결 성, 중앙 유적을 통과할 수 없게 한다.
- 강은 통과할 수 없는 주요 지형으로 처리하되 도로가 교차하는 지점에는 통행 가능한 다리를 둔다.
- 장식용 나무와 선인장은 이번 단계에서 충돌 대상에서 제외해 이동이 지나치게 막히지 않도록 한다.
- X축과 Y축 이동을 나누어 판정해 벽 모서리에서 자연스럽게 미끄러지도록 한다.

## 적 구성

중앙 초원에 슬라임 3마리를 서로 겹치지 않는 고정 위치에 배치한다.

- 최대 HP: 3
- 이동 속도: 플레이어보다 느리게 설정
- 추적 범위: 플레이어가 화면에 접근했을 때 추적을 시작할 정도의 범위
- 공격 방식: 플레이어에게 접촉하면 피해 10
- 접촉 피해 재적용 간격: 1초
- 추적 범위를 벗어나면 최초 위치로 복귀
- 슬라임도 건물과 주요 지형 충돌을 적용받는다.

## 기본 공격

- 입력: Ctrl
- 피해: 1
- 재사용 대기시간: 0.5초
- 플레이어가 바라보는 방향 앞쪽의 짧은 부채꼴 범위를 공격한다.
- 검 궤적을 짧게 표시하고 공격 순간 캐릭터 팔과 검의 위치를 변화시킨다.
- 키를 계속 누른 상태에서는 자동 반복되지 않고 새로 누를 때 한 번만 공격한다.

## 강한 공격

- 입력: Q
- 피해: 3
- MP 소모: 20
- 재사용 대기시간: 4초
- 기본 공격보다 준비 시간이 길고 공격 범위와 검 궤적이 크다.
- 적중한 슬라임을 플레이어가 바라보는 방향으로 강하게 밀어낸다.
- MP가 부족하거나 재사용 대기 중이면 공격하지 않고 HUD 메시지로 이유를 알린다.
- Q 슬롯에는 강한 공격 이름, MP 소모량, 재사용 대기 상태를 표시한다.

## 타격감과 밀쳐내기

공격 적중 시 다음 효과를 조합한다.

- 슬라임이 공격 방향 반대로 빠르게 밀려난 뒤 감속한다.
- 짧은 흰색 피격 점멸을 표시한다.
- 좌우 흔들림과 작은 압축·복원 효과를 적용한다.
- 피해 숫자를 슬라임 위에 잠시 띄운다.
- 기본 공격은 약한 밀쳐내기, 강한 공격은 더 긴 밀쳐내기를 적용한다.
- 밀쳐내기 중에도 월드 경계와 주요 지형을 통과하지 않는다.

## 슬라임 사망

HP가 0이 되면 즉시 삭제하지 않는다.

1. 추적과 접촉 피해를 중지한다.
2. 짧게 튀어 오르며 흔들린다.
3. 약 0.6초 동안 투명도와 크기가 서서히 감소한다.
4. 완전히 사라진 뒤 렌더링과 충돌 목록에서 제거한다.
5. 이번 단계에서는 자동 재생성하지 않는다.

## 플레이어 피해와 부활

- 슬라임 접촉 시 HP가 10 감소한다.
- 피격 직후 1초간 무적 상태를 적용해 연속 피해를 방지한다.
- 피격 시 플레이어를 슬라임 반대 방향으로 조금 밀어내고 붉은 점멸을 표시한다.
- HP가 0이 되면 입력을 잠시 막고 화면을 어둡게 전환한다.
- 약 1.2초 후 중앙 초원 시작 좌표로 이동하고 HP와 MP를 최대치로 회복한다.
- 카메라 위치와 이전 프레임 좌표를 함께 초기화해 부활 순간 화면이 튀지 않게 한다.

## 코드 구조

- `src/game.js`: 게임 루프, 플레이어 상태, 입력, 전투 판정, 피해와 부활 흐름을 관리한다.
- `src/world.js`: 충돌 영역과 강·다리 판정 정보를 제공한다.
- `src/enemies.js`: 슬라임 생성, 추적, 피격, 밀쳐내기, 사망 상태를 관리하는 새 모듈이다.
- `src/combat.js`: 공격 범위와 충돌 계산을 담당하는 새 모듈이다.
- `src/main.js`: 기존 입장과 퇴장 흐름을 유지한다.
- `index.html`과 `styles.css`: 조작 안내, Q 슬롯, 쿨다운 표시와 부활 오버레이를 갱신한다.
- Firebase 위치 동기화 형식은 변경하지 않는다. 적 상태는 이번 단계에서 각 클라이언트 로컬로만 실행한다.

## 오류와 경계 조건

- 공격 중 입장 화면이나 종료 확인창이 열리면 입력과 공격 판정을 중지한다.
- 게임에서 나가거나 다시 입장할 때 적, 쿨다운, 피격, 부활 상태를 초기화한다.
- 동시에 여러 슬라임을 공격할 수 있지만 같은 공격이 한 슬라임에게 여러 번 적용되지 않게 한다.
- Ctrl 키 조합으로 브라우저 기능을 실행하지 않도록 Ctrl 단독 입력만 공격으로 처리한다.
- 창 크기가 달라져도 공격 판정은 월드 좌표를 기준으로 계산한다.

## 검증

- 방향키 네 방향과 대각선 이동 확인
- 모든 주요 구조물과 강의 충돌, 다리 통과 확인
- Ctrl 기본 공격의 방향, 피해, 쿨다운 확인
- Q 강한 공격의 MP 소모, 피해, 쿨다운, 강한 밀쳐내기 확인
- 슬라임 3마리의 추적, 복귀, 접촉 피해 확인
- 슬라임 피격 점멸, 흔들림, 피해 숫자, 사망 소멸 확인
- 플레이어 무적 시간과 HP 0 부활 확인
- 종료 후 재입장 시 상태 초기화 확인
- 데스크톱 브라우저에서 HUD 겹침과 콘솔 오류 확인
- 기존 Firebase 플레이어 위치 동기화와 퇴장 정리 회귀 확인
