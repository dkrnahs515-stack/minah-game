# 사냥 보상 및 렌더링 안정화 설계

## 목표

퀘스트 수락 여부와 관계없이 모든 현재 몬스터 처치에 `3 EXP + 무작위 1~3 Gold`를 지급하고, 캐릭터와 몬스터가 깜빡이는 Canvas 중간 프레임 노출을 제거한다.

## 확정 규칙

- 화염 슬라임, 숲 슬라임, 물방울 슬라임, 멧돼지, 게는 모두 처치 시 `3 EXP + 1~3 Gold`를 지급한다.
- 퀘스트 `모험의 시작` 진행도는 활성 상태에서 슬라임 처치만 계산한다.
- 한 적의 사망 보상은 한 번만 지급한다.
- 한 공격으로 여러 적을 처치하면 각 보상을 합산하되 브라우저 저장은 한 번만 수행한다.
- 기존 레벨업, 초과 EXP 이월, HP·MP 완전 회복, localStorage v2 구조는 변경하지 않는다.

## 구현 경계

- `src/player-progression.js`의 공통 사냥 보상이 EXP와 Gold를 함께 계산한다.
- `src/game.js`는 몬스터 종류와 무관하게 공통 보상을 적용하고, 퀘스트 판정만 별도로 유지한다.
- 메인 Canvas는 `desynchronized` 힌트 없이 불투명 2D context를 사용한다. 매 프레임 지우기와 다시 그리기 사이의 중간 상태가 직접 표시되지 않도록 브라우저 합성 경로를 사용한다.

## 검증

- 퀘스트 미수락 상태에서 멧돼지 처치 후 `EXP 3`, `Gold 1~3`, 퀘스트 상태 `available` 유지
- 슬라임 처치 후 EXP·Gold와 활성 퀘스트 진행도 동시 반영
- 다중 처치 보상과 저장 1회 보장
- Canvas context 옵션 회귀 테스트
- 전체 자동 테스트 후 PR, `main` 병합, GitHub Pages 실플레이 점검

## 제외 범위

- 몬스터 종류별 서로 다른 EXP·Gold 표
- 아이템 드롭과 상점
- Firebase 진행 저장
