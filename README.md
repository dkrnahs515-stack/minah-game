# 낙화참 3D

브라우저에서 실행되는 Three.js 기반 3인칭 액션 게임 프로토타입입니다.

## 조작법

- `WASD` 또는 방향키: 이동
- `Shift`: 달리기
- 마우스: 카메라 회전
- `Z`: 낙화참 사용
- `R`: 적 재생성
- `Esc`: 마우스 잠금 해제

## 낙화참 설정

- 기본 공격력: 25
- 한 틱당 피해: 기본 공격력의 40% = 10
- 타격 횟수: 16회
- 총 피해: 160
- 쿨타임: 5초
- 마나 소모: 35

주요 수치는 `index.html`의 `CONFIG`에서 변경할 수 있습니다.

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages로 배포합니다.
